# Changelog

## 1.0.2

- The menu bar item pulses slowly in the last 10% of a division and quickly once a rank-up is waiting; clicking
  it then plays the reveal. Rank-ups no longer open the reveal on their own.

## 1.0.1

- History and transcript imports run automatically every 90 seconds; the Backfill button is gone (Rescan all
  history stays in the menu). Menu bar refreshes every 30 seconds.

## 1.0.0

- Menu bar rank and stats for every shell command you and any AI agent run.
- Shell hooks for zsh and bash, Claude Code hooks, a registry of about 55 agents with provider and model
  attribution, remote machine sync over ssh.
- Backfill from zsh history, Amazon Q history, Claude Code transcripts and Codex rollouts.
- Ten-tier ladder from Iron to Root with generated emblems, rank reveal with a dial and shatter effect on first
  launch and every rank up.
- Compact popover with headline numbers, expandable full stats, tiers page, share card for X, Bluesky, Threads
  and the macOS share sheet, menu bar settings.
- First-run setup wizard, app icon, release zip.
